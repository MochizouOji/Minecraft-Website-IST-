## About
Built in 2024 for our IST class, this site is finally refactored 2 years later with (slightly) better coding practices, file formats, and page designs. Most of the site has been kept the same to preserve the memories of the late nights spent making it.

This site covers various aspects of Minecraft including version history, dimensions, getting started guides, and a quiz section. It features custom animations, an infinite-scroll image carousel, ambient music, and a Minecraft-inspired visual style.

## Pages

- **Home** — Overview with animated selection boxes linking to each section
- **Versions** — Breakdown of major updates (1.8, 1.9, 1.16, 1.17)
- **Dimensions** — Explore the Overworld, Nether, and End biomes
- **Getting Started** — Guides on crafting, gamemodes, PvP, and redstone
- **Quiz** — Test your Minecraft knowledge
- **Sitemap** — Visual map of the entire site

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- No frameworks or build tools
- Images served in AVIF format for optimal compression
- Hosted via GitHub Pages

## Running Locally

Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/Zechariah-Guo/IST-Minecraft-Website.git
cd IST-Minecraft-Website
start index.html
```

> Note: YouTube embeds require HTTPS to function — they'll show an error when viewed from `file://` protocol. Use the live site link above for the full experience.
